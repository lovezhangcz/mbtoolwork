# 串口屏 UI 方案 v1.0

> 治具显示与人机交互设计。屏：**中显 VTc070C34A**，1024×600，USART3，115200 8N1。
> 协议依据 `doc/VGUS串口屏用户开发指南.pdf`：帧头 `A5 5A`，不启用 CRC；
> 0x80/0x81 寄存器读写，0x82/0x83 变量读写（触摸键值经 0x83 上传）；
> 寄存器 0x01=背光(0x00~0x40)、0x02=蜂鸣(单位 10ms)、0x03~0x04=页面 ID。
>
> 分工：本方案 + 背景图/图标素材（`design/ui_assets/`）由我方提供；
> VGUS4.3 工具内的控件摆放由人工按本文件第 5、6 章的表操作。

## 1. 页面规划

| 页面 ID | 名称 | 背景图 | 说明 |
|---|---|---|---|
| 0 | 主测试页 | bg_main.png | 状态、实时电压电流、计数、总结论、操作按钮 |
| 1 | 测试明细页 | bg_detail.png | 34 个测试项的实测值与判定，两列排布 |
| 2 | 设置页 | bg_setting.png | 背光/蜂鸣/版本信息；门限配置二期预留 |

导航：主页「明细>」→ 页1；主页「设置」（或实体 KEY3 长按）→ 页2；页1/页2「返回」→ 页0。
切页可用 VGUS 按钮控件的"页面切换"属性直接完成，不占用键值；实体键映射见第 4 章。

## 3. VP 变量地址总表

字地址（VP 以字为单位）。固件侧定义见 `code/app_motor_control/source/app/vgus.h`，两者必须一致。

### 3.1 主页 · 状态与结果

| VP | 控件类型 | 长度/格式 | 说明 |
|---|---|---|---|
| 0x0100 | 文本变量 | 32 字（64B） | 当前状态/提示文本，固件写整段 |
| 0x0146 | 数据变量 | 1 字，整数 0~100 | 测试进度 %（进度条控件也绑此地址） |
| 0x0154 | 数据变量 | 1 字，整数 | 已测数量 |
| 0x0155 | 数据变量 | 1 字，整数 | 通过数量 |
| 0x0156 | 数据变量 | 1 字，整数 | 失败数量 |
| 0x0157 | 变量图标 | 1 字：0/1/2 | 总结论大图标（0=未测 1=PASS 2=FAIL），指 96×96 图标库 |
| 0x0158 | 数据变量 | 1 字，1 位小数 | 测试耗时，单位 0.1s |
| 0x0160 | 文本变量 | 8 字（16B） | 被测主板机型/版本，顶栏"主板："槽 |

### 3.2 主页 · 治具采样（ADS131，左面板）

| VP | 控件类型 | 格式 | 说明 |
|---|---|---|---|
| 0x0140 | 数据变量 | 2 位小数 | 母线电压，单位 0.01V（固件写 mV/10） |
| 0x0141 | 数据变量 | 3 位小数 | 12V 电压，单位 mV |
| 0x0142 | 数据变量 | 3 位小数 | 5V 电压，单位 mV |
| 0x0143 | 数据变量 | 3 位小数 | 3.3V 电压，单位 mV |

### 3.3 主页 · 主板回读（UART4，右面板）

| VP | 控件类型 | 格式 | 说明 |
|---|---|---|---|
| 0x0150 | 数据变量 | 2 位小数 | 主板回读母线电压，单位 0.01V |
| 0x0144 | 数据变量 | 2 位小数，有符号 | 总电流，单位 0.01A |
| 0x0145 | 数据变量 | 2 位小数，有符号 | MOS 温度，单位 0.01℃ |
| 0x0151 | 数据变量 | 3 位小数 | CPU 电压，单位 mV |
| 0x0152 | 数据变量 | 整数 | 遥控通讯计数 |
| 0x01E0 | 文本变量 | 8 字（16B） | 报警字，固件写 HEX 字符串（如 "0041"）——原 0x0153 数据变量方案废弃（v1.1） |

### 3.4 明细页 · 34 项结果

| VP | 控件类型 | 说明 |
|---|---|---|
| 0x0180 + i×2 | 数据变量（s16） | 第 i 项实测值（i=0~33），小数位按项配置，见下表 |
| 0x0180 + i×2 + 1 | 变量图标 | 第 i 项判定：0=未测 1=过 2=败，指 48×48 图标库 |

34 项顺序与 `code/app_motor_control/source/app/jig_proto.c` 的 `s_item_names` 一致：

| 序号段 | 内容 | 建议小数位 |
|---|---|---|
| 0~8 | 左/右轮 A/B/C 相 零偏·静态·吸附电流 | 2 位（0.01A） |
| 9~12、22~25 | 左/右 霍尔低位·高位·速度·错误 | 霍尔电平 3 位小数（V）；速度整数（rpm）；错误计数整数 |
| 26 | 母线电压 | 2 位（0.01V） |
| 27~29 | 母线电流零偏/静态/吸附总电流 | 2 位（0.01A） |
| 30~31 | MOS 温度低限/高限 | 2 位（0.01℃） |
| 32 | CPU 电压 | 3 位（mV） |
| 33 | 遥控通信计数 | 整数 |

> 注意：各项"实测值"的数值缩放（单位）必须与固件 `jig_proto.c` 上报一致，
> 目前按上表单位约定；若后续协议改单位，同步改 VGUS 控件小数位。

### 3.5 设置页

| VP | 控件类型 | 说明 |

## 4. 触摸键值表

按钮键值（写 VP 0x0200 的属性里"键值"字段）：

| 键值 | 按钮 | 所在页 | 固件动作 |
|---|---|---|---|
| 0x0001 | 启动测试 | 主页 | 启动完整测试流程（等同实体 KEY1） |
| 0x0002 | 重新测试 | 主页 | 清结果后重跑（等同实体 KEY2） |
| 0x0003 | 停 止 | 主页 | 中止当前测试，断主继电器 |
| 0x0004 | 明细> | 主页 | 切页 1（也可用页面切换属性，不占键值） |
| 0x0005 | 返回 | 页1/页2 | 切页 0 |
| 0x0010 | 设置 | 主页 | 切页 2（实体 KEY3 长按等效） |
| 0x0011 | 背光 ＋ | 设置页 | 背光 +4，写寄存器 0x01 并回写 0x0170 |
| 0x0012 | 背光 － | 设置页 | 背光 −4，同上 |
| 0x0013 | 蜂鸣器测试 | 设置页 | 屏蜂鸣：写寄存器 0x02=50（0.5s） |
| 0x0014 | 被测板蜂鸣 | 设置页 | 经 UART4 协议让被测板鸣叫 |

实体键：KEY1=启动测试、KEY2=重新测试、KEY3 短按=主页/明细页切换、长按=进设置页。
固件侧在 `app_main.c` bluetoothtast（40Hz）里对 `g_vgus_touch.key` 做 switch 映射（当前为 TODO 占位）。

## 7. 固件写入逻辑（已实现/待补）

| 时机 | 动作 | 代码位置 |
|---|---|---|
| 上电初始化 | 读屏版本（0x81 读 0x00），切主页，写初始状态文本 | test_flow.c |
| 40Hz 任务 | `vgus_poll()` 解析触摸/应答；空闲时刷新 0x0140~0x0143 四路电压 | app_main.c bluetoothtast |
| 测试中每步 | 写状态文本 0x0100、进度 0x0146 | test_flow.c `ui_refresh_state()` |
| 测试中实时 | 写总电流 0x0144、MOS 温度 0x0145（`g_jig_rt`） | test_flow.c |
| 每项出结果 | 写 0x0180+i×2 值与判定（可批量 `vgus_write_words`） | test_flow.c |
| 流程结束 | 写计数 0x0154~0x0156、耗时 0x0158、总结论图标 0x0157、批量写 68 字项结果，自动切明细页 | test_flow.c |
| 触摸键值 | 40Hz 任务 switch 映射（当前 TODO，按第 4 章键值表实现） | app_main.c |
| 背光/蜂鸣 | 写寄存器 0x01/0x02；背光值同步回写 0x0170 | vgus.c |

## 8. VGUS4.3 工具操作步骤

1. 新建工程，屏参：VTc070C34A / 1024×600 / 波特率 115200 / 帧头 A5 5A / **CRC 关闭**。
2. 导入 3 张背景图，建 3 个页面（ID 0/1/2）并各绑定对应背景。
3. 导入 6 张 PNG 图标生成图标库（ICO）：建议图标 0/1/2 = idle/pass/fail，与 VP 写入值对应。
4. 按第 3 章 VP 表 + 第 5 章坐标摆控件：文本变量、数据变量（设小数位）、变量图标、进度条、"按键值返回"按钮（键值按第 4 章）。
5. 键值上传地址统一设 0x0200；按钮按压动作用 VGUS 默认即可（背景图上已画好按钮外观，控件设透明底）。
6. 生成配置，TF 卡下载到屏。
