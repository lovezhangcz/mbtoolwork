# 治具 ↔ 被测主板 对接通信协议

| 项目 | 内容 |
|---|---|
| 协议版本 | JIG_PROTO V1.0（草案） |
| 日期 | 2026-11-15 |
| 设计原则 | **主板侧改动最小化**：复用现有 20 字节帧格式、UART4 通道、selfcheck 自检逻辑；主板侧仅新增 1 个命令分支 + 1 个结果上报函数 |
| 约束文件 | 治具固件与被测板固件双方均按本文档实现 |

---

## 1. 物理层与帧格式（沿用现有，不改）

- 通道：被测板 **UART4**，115200 8N1（治具侧 CN8 主板串口，经隔离器）
- 帧：固定 20 字节

```
偏移    0     1     2........15      16        17          18    19
      ┌─────┬─────┬──────────────┬─────────┬───────────┬─────┬─────┐
      │0xAA │0x5A │   14字节数据  │  CMD    │  校验      │0x5A │0x55 │
      └─────┴─────┴──────────────┴─────────┴───────────┴─────┴─────┘
```

- 校验 = (字节0~16 累加和) ^ 0xFF
- 治具命令统一使用 **CMD = 0xC8**；主板应答/上报统一使用 **CMD = 0xC9**
- 数据区内多字节量均为**小端**

> 选择 0xC8/0xC9 的原因：现有协议已占用 0x1C/0x9B/0x88/0x70/0x65/0x66/0xA9/0xB9/0xF5/0xF6，0xC8/0xC9 无冲突，且被测板校验逻辑对该 CMD 无豁免问题。

## 2. 命令定义（治具 → 主板，CMD=0xC8）

数据区 [2] = 子命令，[3] 起为参数。

| 子命令 | 名称 | 参数 | 说明 |
|---|---|---|---|
| 0x01 | 握手/读版本 | 无 | 任何时候可发；同时使能主板对治具的上报通道 |
| 0x02 | 启动整套自检 | 无 | 等价于现有 0x1C/C9 触发，但结果走本协议二进制上报 |
| 0x03 | 停止自检/电机急停 | 无 | 任何时刻可发，安全兜底 |
| 0x04 | 查询自检进度 | 无 | 治具轮询用（建议 200ms 周期） |
| 0x10 | 读实时数据 | 无 | 电压/电流/温度/报警/遥控计数一帧带回 |
| 0x21 | 电机分步测试（预留） | [3]=电机号(0左1右) [4]=阶段(1吸附/2空转/3负载) [5~6]=Vq [7~8]=时长(10ms) | 二期：治具单独控制某个电机测试阶段，便于单点复测 |

### 2.1 主板应答统一格式（CMD=0xC9）

| 子命令 | [3] | [4..15] |
|---|---|---|
| 0x01 握手应答 | 0=OK | [4..11]=机型码 ASCII 8 字节，[12..15]=版本 ASCII 4 字节 |
| 0x02/0x03 执行应答 | 结果码 | 0=接受，1=拒绝(车速非零)，2=拒绝(充电中)，3=自检进行中 |
| 0x04 进度应答 | 0=OK | [4]=当前步骤号 [5]=总步骤数 [6]=已出结果项数 [7]=当前失败项数 |
| 0x10 实时数据应答 | 0=OK | [4..5]=母线电压(0.01V) [6..7]=总电流(0.01A) [8..9]=MOS温度(0.01℃) [10..11]=CPU电压(mV) [12]=commu_cnt [13]=自检状态(0空闲1进行2完成) [14..15]=thiswarn 报警字 |

## 3. 主板主动上报（CMD=0xC9，无需治具请求）

### 3.1 单项测试结果上报（自检每完成一项即推一帧）

| 偏移 | 内容 |
|---|---|
| [2] | 0x20 |
| [3] | 测试项索引（对应 selfcheck 的 checkresault[] 下标，见 §4） |
| [4..5] | 实测值（s16） |
| [6] | 判定：1=PASS，0=FAIL |
| [7..8] | 下限 thr_l |
| [9..10] | 上限 thr_h |
| [11..15] | 保留 0 |

> 名称对照表由治具侧保存（§4），主板不发送名称字符串——比现有文本行上报更省、解析更可靠。

### 3.2 自检完成上报

| 偏移 | 内容 |
|---|---|
| [2] | 0x22 |
| [3] | 总测试项数 |
| [4] | 通过项数 |
| [5] | 失败项数 |
| [6..7] | 自检总耗时（0.1s） |
| [8] | 总结论：1=PASS，0=FAIL |

## 6. 治具侧实现要点

1. 帧解析：与主板同一套 20 字节帧 + 累加和校验（治具 USART2 中断 + DMA/环形缓冲）
2. 测试流程中：启动自检(0x02)后，200ms 轮询进度(0x04)，同时接收 3.1 结果推送实时刷新屏幕；收到 3.2 完成帧后汇总
3. 超时：整套自检建议超时 ≥20s；单项结果推送间隔异常（>3s 无新项）视为卡死，发 0x03 停止后判 FAIL
4. 自检期间如需电压电流显示，用 0x10 主动查询（不要依赖 0xA9 周期包——自检期间停发）
5. 重测 = 重发 0x02；取消 = 发 0x03 后走断电放电流程
