## 1. 概述

本治具用于双驱四轮滑板车主板（DUT, Device Under Test）的产线功能检测。治具以 GD32F103RCT6 为主控，通过数字隔离器与被测板完全电气隔离，完成**供电控制、电压采集、串口通信、按键模拟、结果显示**五大类工作，测试结果通过 7 寸 VGUS 串口屏（VTc070C34A）+ 蜂鸣器 + 指示灯呈现给操作员。

### 1.1 测试对象供电

- 电池规格：10 串锂电池，标称 36V，满电 42V
- 治具通过继电器 RLY1（BTIN→BTO）控制被测板主电源通断
- 上电分两步：**先通电（继电器吸合），再启动（ACT_SW 模拟按被测板开机键）**

### 1.2 隔离域划分

| 域 | 供电 | 包含内容 |
|---|---|---|
| MCU 域 | ISO_5V → ISO_3V3（USB2 Type-C） | GD32F103RCT6、SWD、运行灯、蜂鸣器 |
| 执行/被测域 | PD_5V → PD_3V3（USB1 Type-C） | 被测板接口、采样前端、串口屏接口、继电器、按键 |

两域之间所有信号经 CA-IS3722HS / CA-IS3720LS 数字隔离器传输。

### 2.2 电压采样通道（ADS131M04，24 位 Σ-Δ ADC，SPI 接口）

| ADC 通道 | 采样口 | 被测对象 | 分压比 | 满电时 ADC 输入 |
|---|---|---|---|---|
| AIN0 | CN4 母线采样 | 电池母线电压 | 200K/10K（21:1） | 42V → 2.0V ⚠ |
| AIN1 | CN5 12V采样 | 被测板 12V 轨 | 47K/10K（5.7:1） | 12V → 2.1V ⚠ |
| AIN2 | CN6 5V采样 | 被测板 5V 轨 | 30K/20K（2.5:1） | 5V → 2.0V ⚠ |
| AIN3 | CN7 3.3V采样 | 被测板 3.3V 轨 | 6.2K/10K（1.62:1） | 3.3V → 2.04V ⚠ |

> ⚠ **疑点（已反馈，待硬件确认）**：ADS131M04 内部基准 1.2V，PGA=1 时满量程 ±1.2V。按现有分压比，四路采样在正常工况下都会超过满量程导致读数饱和。**【待确认：是否修改分压电阻，或确认芯片供电/基准用法】**
>
> 建议修正值（供参考）：母线路 360K/10K（42V→1.14V）、12V 路 100K/10K（12V→1.09V）、5V 路 39K/10K（5V→1.02V）、3.3V 路 22K/10K（3.3V→1.03V）。

### 3.2 各状态详细定义

| 状态 | 动作 | 通过条件 | 失败处理 | 超时 |
|---|---|---|---|---|
| SELF_CHECK | ① 读 ADS131M04 ID 寄存器验证 SPI 通信<br>② 串口屏握手（读屏版本/握手帧）<br>③ 蜂鸣器短响一声、三按键灯自检闪烁 | 全部通过 | 屏显示自检失败项（如屏本身故障则蜂鸣器长鸣 + 运行灯快闪），停在 SELF_ERR | 3s |
| WAIT_BOARD | 屏显示"请放置主板"，KEY1 灯慢闪提示；放电回路保持有效 | 操作员按 KEY1 | — | 无（一直等待） |
| PRE_CHECK | 继电器断开状态下读四路电压 | 四路均 < 安全阈值（建议各 < 1V）**【待确认】**，判定无残留电压、无异常短路 | 报"被测板异常/残留电压"，FAIL | 2s |
| POWER_ON | 吸合继电器 RLY1（ACT_MB_ON 有效），等待母线电压建立 | 母线电压进入窗口（见 §4） | 报"主电源未建立"，FAIL → POWER_OFF | 2s |
| BOOT_DUT | 驱动 ACT_SW 模拟开机键（脉冲宽度 **【待确认】**，默认 500ms），释放后通过 ACT_ON 检测被测板启动状态 | ACT_ON 电平符合预期 / 串口有响应 | 报"被测板未启动"，FAIL → POWER_OFF | 3s |
| VOLTAGE_TEST | 连续采样四路电压 N 次取平均（建议 N=16） | 每路在门限窗口内（§4） | 记录失败项与实测值，**继续测后续项**（电源异常不等于其他项不能测） | 2s |
| COMM_TEST | 主板串口发送握手帧，读固件版本、状态字 | 收到正确应答、版本号格式合法 | 报"通信失败"，FAIL → 跳至 RESULT（后续依赖通信的功能项全部判失败） | 1s×3 次重试 |
| FUNC_TEST | 按 §4.3 逐项执行功能测试 | 各项分别判定 | 记录每项结果，全部测完 | 每项独立超时 |
| RESULT | 屏显示总结论：PASS（绿底）/ FAIL（红底 + 失败项列表）；蜂鸣器与按键灯按 §5.2 输出 | — | — | 保持显示直到按键 |
| POWER_OFF | ① 断开继电器 ② ACT_DISCHG 放电 ③ 采样母线确认 < 安全电压（建议 < 5V）**【待确认】** ④ 屏提示"请取下主板" | 母线放电完成 | 放电超时则报警提示人工处理 | 放电 5s |

### 3.3 失败策略

- **安全类失败**（PRE_CHECK 异常、POWER_ON 异常）：立即终止测试，安全收尾
- **判定类失败**（电压超差、功能项不合格）：记录后继续测完所有可测项，最后统一显示——操作员一次看到全部问题，避免反复装板
- **通信失败**：依赖串口的功能项无法执行，统一标记为"未测/失败"

## 7. 通信协议定义（草案）

### 7.1 治具 ↔ 串口屏（VGUS 协议）

遵循中显 VGUS 标准帧：`5A A5 + 长度 + 命令 + 数据`，治具侧只用三类指令：

| 命令字 | 方向 | 用途 |
|---|---|---|
| 0x82 | 治具→屏 | 写变量存储器（刷新电压值、判定结果、提示语） |
| 0x80 | 治具→屏 | 写寄存器（切页、背光控制） |
| 0x83 | 屏→治具 | 触摸/键值上传（设置页参数修改） |

变量地址分配表随界面设计一并输出。

### 7.2 治具 ↔ 被测板（测试协议，帧格式草案）

> 若被测板沿用平衡车项目的 bbcpro 协议，本节作废、以该协议为准。**【待确认】**

物理层：UART，波特率 **【待确认，建议 115200】**，8N1。

帧格式（小端）：

```
┌────────┬────────┬────────┬────────┬───────────┬─────────┐
│ HEAD0  │ HEAD1  │  LEN   │  CMD   │  DATA     │  CRC16  │
│ 0xAA   │ 0x55   │ 数据长  │ 命令字  │ 0~N 字节  │ 2 字节   │
└────────┴────────┴────────┴────────┴───────────┴─────────┘
```

- LEN = CMD + DATA 的字节数
- CRC16：Modbus CRC16（多项式 0xA001），覆盖 LEN + CMD + DATA
- 应答帧同格式，CMD 最高位置 1（CMD | 0x80），DATA 首字节为结果码（0=OK）

命令字草案：

| CMD | 功能 | 数据 |
|---|---|---|
| 0x01 | 握手 | — |
| 0x02 | 读固件版本 | 返回主.次.修订 |
| 0x03 | 读状态字 | 电池、充电、故障位 |

## 8. 软件架构（映射到现有 uCOS-II 框架）

| 任务 | 原框架任务 | 改造后职责 |
|---|---|---|
| App_TaskStart | 启动任务 | 初始化后转为心跳/喂狗 |
| CSensorTask | 传感器采样 | **ADC 采样任务**：软件 SPI 读 ADS131M04，滤波平均 |
| CMotionTask | 运动处理 | **测试流程任务**：§3 状态机主体 |
| CSystemSuperiseTask | 系统监控 | **按键扫描 + 声光输出**（KEY1~3、蜂鸣器、按键灯、运行灯） |
| CUsartCommTask | 串口通信 | **被测板串口协议**收发与解析 |
| bluetoothtast | 蓝牙数据 | 改为**屏幕通信任务**：VGUS 帧收发、界面刷新 |
| spkworkingtast | 喇叭任务 | 可删除或作为低优先级杂项任务 |

TIM3 的 2kHz 时基中断保留，作为按键扫描、灯闪、超时节拍的统一时基。
