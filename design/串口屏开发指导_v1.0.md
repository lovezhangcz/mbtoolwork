> **2026-11-19 更新：屏工程已由脚本直接生成，无需手工摆控件！**
> 工程位于 `screen/JIG_SCREEN/`（`JIG_SCREEN.vt` + IMAGE/ + ICON/ + FONT/ + CONFIG.txt 等），
> 用 VGUS2021 打开 `JIG_SCREEN.vt` → 检查 → 编译 → TF 卡下载即可（见第 5 章）。
> 本文第 1~4 章的手工建工程步骤保留作**核对与重建参考**；若工程能正常打开编译，可跳过。

> 面向操作者的实操手册：用 VGUS4.3/VGUS2021 把 `design/ui_assets/` 的素材做成屏工程并下载到 VTc070C34A。
> 设计依据：`design/屏幕UI方案_v1.0.md`（VP 地址、坐标、键值、配色全部以它为准，本文不再重复表格，只做"怎么操作"）。

## 0. 准备

| 物品 | 说明 |
|---|---|
| VGUS4.3 开发软件 | 中显官方工具，装在 PC 上 |
| 素材 | `design/ui_assets/`：bg_main.png、bg_detail.png、bg_setting.png、6 张图标 PNG |
| TF 卡 | ≤32G，FAT32 格式化，用于下载工程到屏 |
| USB 转串口 | 联调时接屏的 UART（TTL 电平） |

## 1. 新建工程与屏参配置

1. 打开 VGUS4.3 → 新建工程，工程名建议 `JIG_SCREEN`。
2. 屏参设置（**最关键，错了通讯不上**）：
   - 分辨率：**1024×600**
   - 波特率：**115200**，8 数据位 / 无校验 / 1 停止位
   - 帧头：**A5 5A**（不是 5A A5）
   - CRC 校验：**关闭/不启用**
3. 确认变量存储器按**字地址**编址（VP 表里 0x0140 就是一个字，不是字节地址）。

## 2. 导入背景图，建页面

1. 把 3 张背景图导入工程的图片库。
2. 建 3 个页面，页面 ID 必须按下表（固件按此切页）：

| 页面 ID | 绑定背景 | 名称 |
|---|---|---|
| 0 | bg_main.png | 主测试页 |
| 1 | bg_detail.png | 测试明细页 |
| 2 | bg_setting.png | 设置页 |

3. 上电默认页设为 **0**。

## 3. 制作图标库（ICO）

1. 用 VGUS 图标库工具，把图标 PNG 合成一个 ICO 文件，**顺序必须固定**。本项目已生成 `ICON/40ICO/`（编号 40.ICO），索引如下：

| 图标索引 | 内容 | 尺寸 | 用途 |
|---|---|---|---|
| 0 / 1 / 2 | 未测(－) / 通过(√) / 失败(×) | 24×24 | 明细页单项判定（VP 0x0180+i×2+1，值 0/1/2） |
| 3 / 4 / 5 | 总结论 未测 / PASS / FAIL | 96×96 | 主页总结论（VP 0x0157，值 0/1/2） |
| 6 | 进度条填充条 | 112×22 | 主页进度条（VP 0x0146） |

2. 明细页判定图标区为 36×24 槽位，故用 24×24 图标（早期方案的 48×48 仅作素材保留在 design/ui_assets/，不上屏）。

## 4. 摆放控件

### 通则

- 所有坐标、VP 地址、小数位数**照抄**《屏幕UI方案 v1.0》第 3、5 章的表，不要凭感觉挪位置——槽位已画在背景图上，控件对齐槽位即可。
- 按钮外观已经画在背景图里，所以**按钮控件设为透明底/无图标**，只用它的触摸区域 + 键值返回功能。
- 字体颜色从方案第 6 章的 RGB565 表取：普通数值 0xCE7B，通过 0x2EAE，失败 0xFA2A，弱文本 0x7C12。
- 文本变量（0x0100、0x0160、0x0168）编码选 **GBK**，字长按表设置（32/8/8 字）。

### 页0 主测试页（14 个控件）

| 控件 | 类型 | VP | 要点 |
|---|---|---|---|
| 状态文本 | 文本变量 | 0x0100 | 32 字，GBK |
| 进度条 | 进度条 | 0x0146 | 范围 0~100，横向 |
| 进度数值 | 数据变量 | 0x0146 | 与进度条同 VP，整数 |
| 母线/12V/5V/3.3V | 数据变量 ×4 | 0x0140~0x0143 | 母线 2 位小数，其余 3 位（mV→V） |
| 回读母线/总电流/温度/CPU/遥控/报警 | 数据变量 ×6 | 0x0150 / 0x0144 / 0x0145 / 0x0151 / 0x0152 / 0x0153 | 小数位 2/2/2/3/0，报警字选 **HEX 显示**；电流温度勾"有符号" |
| 已测/通过/失败 | 数据变量 ×3 | 0x0154/0x0155/0x0156 | 整数 |
| 耗时 | 数据变量 | 0x0158 | 1 位小数 |
| 总结论图标 | 变量图标 | 0x0157 | 映射见第 3 节 |
| 主板机型 | 文本变量 | 0x0160 | 8 字 |
| 按钮 ×5 | 按键值返回 | 键值 0x0001/0x0002/0x0003/0x0004/0x0010 | 启动/重测/停止/明细/设置，**上传地址统一 0x0200** |

「明细>」和「设置」也可以改用"页面切换"按钮直接跳页；用键值返回则固件收到后切页，二选一，**推荐键值返回**（固件记录操作日志）。

### 页1 明细页（69 个控件）

- 34 个数据变量：VP = 0x0180 + i×2（i=0~33），有符号，小数位按方案 §3.4 表（电流类 2 位、霍尔电平 3 位、速度/计数 0 位、电压 2 位、温度 2 位、CPU 电压 3 位）。
- 34 个变量图标：VP = 0x0180 + i×2 + 1，映射 0/1/2。
- 1 个返回按钮：键值 0x0005。
- 技巧：先做好第 0 项的一对控件，复制粘贴后按行基 y=84+(i%17)×30、列 x=24 或 524 批量改坐标和 VP，注意 VP 是逐项 +2。

### 页2 设置页（8 个控件）

| 控件 | 类型 | VP/键值 |
|---|---|---|
| 背光 － / ＋ | 按键值返回 ×2 | 0x0012 / 0x0011 |
| 背光值回显 | 数据变量 | 0x0170（整数） |
| 蜂鸣器测试 / 被测板蜂鸣 | 按键值返回 ×2 | 0x0013 / 0x0014 |
| 治具固件版本 | 文本变量 | 0x0168（8 字） |
| 主板机型 | 文本变量 | 0x0160（8 字，与主页同 VP） |
| 返回 | 按键值返回 | 0x0005 |

## 5. 下载到屏

1. 工程生成/导出，得到 TF 卡下载文件（VGUS 工具"下载"功能生成到 TF 卡根目录）。
2. 屏断电 → 插 TF 卡 → 上电，屏自动烧录，提示完成后断电拔卡。
3. 重新上电应显示页0 背景与空槽位。

## 6. 联调验证（先用串口助手，再接治具）

屏接 USB 转串口（115200 8N1），用串口助手发帧验证各控件（帧格式：A5 5A + 长度 + 指令 + 数据，长度=指令+数据的字节数）：

| 目的 | 发送（HEX） | 预期 |
|---|---|---|
| 写母线电压 40.00V | `A5 5A 05 82 01 40 0F A0` | 主页母线槽显示 40.00 |
| 写状态文本"待机" | `A5 5A 09 82 01 00 B4 FD BB FA FF FF` | 状态槽显示"待机"（文本末尾必须 FF FF 结束符） |
| 写总结论 PASS | `A5 5A 05 82 01 57 00 01` | 大图标变绿 √ |
| 写第0项=1.23A 判定过 | `A5 5A 07 82 01 80 00 7B 00 01` | 明细页 00 项显示 1.23 和绿图标 |
| 切到明细页 | `A5 5A 04 80 03 00 01` | 显示页1 |
| 蜂鸣 0.5s | `A5 5A 03 80 02 32` | 屏响一声 |
| 背光半亮 | `A5 5A 03 80 01 20` | 背光变暗 |
| 点任意按钮 | （手触屏） | 串口收到 `A5 5A 06 83 02 00 01 <键值H> <键值L>` |

全部通过后，再接治具主板（USART3）做整机联调。

## 7. 常见问题（踩坑清单）

1. **通讯不上**：先查帧头是不是 A5 5A、CRC 是否关闭、波特率 115200——三项占 90% 的问题。
2. **数值差 10/100 倍**：控件小数位没按表设，或固件写的单位变了（改单位必须固件和屏一起改）。
3. **文本乱码/残留**：编码没选 GBK，或上次内容比这次长——固件写文本会自动补 0xFFFF 结束符，屏端字长要留够。
4. **图标不显示**：变量图标映射的"最大值/最小值"没覆盖 0~2，或 ICO 顺序错了。
5. **按键没反应**：按钮控件的"键值返回"属性里上传地址必须是 0x0200，且页面变量里没和别的控件撞 VP。
6. **页1 控件错位**：明细页 68 个结果控件最容易复制错 VP，抽查第 0、17、33 项即可发现规律错误。

## 8. 与固件的接口约定（给固件同事的一句话版）

- 屏只认 VP 表（方案第 3 章），固件任何写入不要超出表内地址。
- 固件→屏：0x82 写变量、0x80 写寄存器（切页/背光/蜂鸣）。
- 屏→固件：只有 0x83 键值上传（VP 0x0200，键值表见方案第 4 章）。
- 改需求先改《屏幕UI方案 v1.0.md》的表，屏工程和固件同步改，禁止单边改地址。
